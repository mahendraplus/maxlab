Data Structures Viva: Questions & Answers

1. Basics

Q: Data Structure kya hota hai?A: Data ko organize karne ka tarika.
Q: Types?A: Linear (Array, Stack), Non-linear (Tree, Graph).
Q: Static vs Dynamic?A: Static = fixed size, Dynamic = flexible.
Q: Linear vs Non-linear?A: Linear = sequence; Non-linear = hierarchy.

2. Arrays

Q: Array kya hai?A: Similar type ka fixed-size collection.
Q: 1D vs 2D Array?A: 1D = list; 2D = matrix (rows × cols).
Q: Insertion/Deletion?A: Elements shift karne padte hain.
Q: Pros & Cons?A: Fast access, but fixed size.

3. Linked List

Q: Linked List kya hai?A: Nodes ka chain with pointers.
Q: Types?A: Singly, Doubly, Circular.
Q: LL vs Array?A: LL = dynamic, Array = fixed & fast access.
Q: Insertion/Deletion?A: Pointer adjust kar ke karte hain.

4. Stack

Q: Stack kya hai?A: LIFO structure.
Q: Operations?A: push(), pop(), peek().
Q: Uses?A: Undo, Expression evaluation.

5. Queue

Q: Queue kya hai?A: FIFO structure.
Q: Types?A: Simple, Circular, Priority, Deque.
Q: Example?A: Printer queue.

6. Trees

Q: Tree kya hota hai?A: Hierarchical DS.
Q: Binary Tree vs BST?A: BST me left < root < right.
Q: Traversals?A: Inorder, Preorder, Postorder.

7. Graph

Q: Graph kya hota hai?A: Nodes & Edges ka set.
Q: Directed vs Undirected?A: Directed me direction hota hai.
Q: Representation?A: Matrix & List.
Q: DFS vs BFS?A: DFS = depth-wise, BFS = level-wise.

8. Searching

Q: Linear vs Binary Search?A: Linear = sequential, Binary = divide & search.
Q: Binary search kab?A: Jab array sorted ho.
Q: Time Complexity?A: Linear = O(n), Binary = O(log n).

9. Sorting

Q: Bubble Sort?A: Adjacent swap repeatedly.
Q: Insertion Sort?A: Sorted part me insert karta hai.
Q: Selection Sort?A: Min element ko correct jagah rakhta hai.
Q: Merge vs Quick?A: Merge = O(n log n), Quick = fast but worst O(n²).

10. Hashing

Q: Hashing?A: Key ko index me convert karna.
Q: Hash Function?A: Key se index generate karta hai.
Q: Collision handling?A: Chaining, Linear probing.

11. Recursion

Q: Recursion?A: Function khud ko call kare.
Q: Base case?A: Stop condition for recursion.
Q: Recursion vs Iteration?A: Recursion = calls, Iteration = loops.

12. Complexity

Q: Time Complexity?A: Algorithm ka run time.
Q: Big O Notation?A: Worst case measure karta hai.
Q: Common Complexities?A: O(1), O(n), O(log n), O(n²).
